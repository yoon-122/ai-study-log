# Activation Function

활성화 함수는 딥러닝에서 중요한 역할을 한다.

입력값을 변환해
신경망이 복잡한 패턴을 학습할 수 있도록 도와준다.

---

## Sigmoid

출력값을 0~1 사이로 변환한다.

### 장점
- 확률처럼 해석 가능

### 단점
- 기울기 소실(Vanishing Gradient) 문제 발생 가능

---

## ReLU

현재 가장 많이 사용되는 활성화 함수 중 하나.

음수는 0,
양수는 그대로 출력한다.

### 장점
- 계산이 빠름
- 학습 성능이 좋음

### 단점
- 음수 구간 뉴런이 죽는 문제 발생 가능

---

## Leaky ReLU

ReLU의 단점을 보완한 함수.

음수에서도 작은 값을 유지한다.

---

## Softmax

출력값들을 확률 형태로 변환한다.

주로 다중 분류 문제에서 사용한다.

---

## 느낀 점
활성화 함수 하나만 바뀌어도
딥러닝 성능이 크게 달라질 수 있다는 점이 흥미로웠다.
