# Classification vs Regression

머신러닝 문제는 크게
분류(Classification)와 회귀(Regression)로 나뉜다.

---

## Classification

정답이 특정 카테고리로 나뉘는 문제.

예시:
- 스팸 메일 판별
- 합격 / 불합격
- 고양이 / 강아지 분류

### 특징
출력이 끊어진 값.

예:
- 0 또는 1
- A / B / C

---

## Regression

연속된 숫자를 예측하는 문제.

예시:
- 주가 예측
- 매출 예측
- 온도 예측

### 특징
출력이 연속적인 값.

---

## 느낀 점
분류는 “정답 맞추기” 느낌이고,
회귀는 “숫자 예측” 느낌으로 이해하니까 조금 더 편했다.
