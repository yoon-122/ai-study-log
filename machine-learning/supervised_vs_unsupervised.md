# Supervised vs Unsupervised Learning

머신러닝 학습 방식은
지도학습과 비지도학습으로 나뉜다.

---

## Supervised Learning

정답(Label)이 있는 데이터를 사용한다.

예시:
- 사진 + 정답
- 스팸 여부 표시된 이메일

모델은 입력과 정답 관계를 학습한다.

---

## Unsupervised Learning

정답 없이 데이터 패턴을 찾는다.

대표적인 예:
- 군집화(Clustering)

비슷한 데이터끼리 그룹을 나누는 방식.

---

## 느낀 점
지도학습은 “정답 있는 문제집” 느낌이고,
비지도학습은 “데이터 특징을 찾아라” 느낌인것 같다.
